# مسار مشاريع Vibe Coding

أداة متابعة مشاريع الطالبات لفعالية الذكاء الاصطناعي و Vibe Coding — جامعة جدة، كلية الحوسبة وتقنية المعلومات، فرع خليص.

الطالبات يحدّثن تقدمهن بأنفسهن برمز مجموعة (بدون إنشاء حسابات)، والمشرفة ترى كل شيء لحظياً: الحالة، الملاحظات، التأخير، الدرجات.

---

## ما الذي تحصلين عليه

| الدور | ماذا يستطيع |
|---|---|
| **زائر** (أي شخص لديه الرابط) | مشاهدة اللوحة والخط الزمني وسجل الخطوات |
| **مجموعة** (برمز مثل `VC-4K7M`) | تحديث حالة مراحلها، كتابة ما أُنجز، رفع روابط النموذج والبوستر، تعبئة بطاقة الفكرة |
| **المشرفة** (بريد + كلمة مرور) | كل ما سبق + اعتماد المراحل، رصد الدرجات، تعديل المواعيد والأوزان، إنشاء المجموعات ورموزها، تصدير CSV |

**فصل الصلاحيات:** الطالبات يكتبن «سلّمنا» فقط — **الاعتماد والدرجة للمشرفة وحدها**، والدرجات غير مرئية للطالبات إطلاقاً (محمية على مستوى قاعدة البيانات، لا على مستوى الواجهة).

---

## التشغيل — ٦ خطوات (حوالي ٢٠ دقيقة)

### ١. أنشئي قاعدة البيانات
1. ادخلي [supabase.com](https://supabase.com) وسجّلي بحساب GitHub أو بريدك.
2. **New project** → اختاري اسماً، وكلمة مرور لقاعدة البيانات (احفظيها)، والمنطقة `Frankfurt` أو الأقرب.
3. انتظري دقيقتين حتى يجهز المشروع.

### ٢. أنشئي الجداول
1. من القائمة الجانبية: **SQL Editor** → **New query**.
2. افتحي ملف [`supabase/schema.sql`](supabase/schema.sql) من هذا المستودع، وانسخي محتواه كاملاً والصقيه.
3. اضغطي **Run**. يجب أن تظهر `Success`.

### ٣. أنشئي حساب المشرفة
1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. أدخلي بريدك وكلمة مرور، وفعّلي **Auto Confirm User**.
3. مهم: **Authentication → Providers → Email** ثم أوقفي **Enable sign-ups** حتى لا يُنشئ أحد حساباً بصلاحية مشرفة.

### ٤. انسخي مفاتيح الاتصال
1. **Project Settings** → **Data API**.
2. انسخي `Project URL` و `anon public key`.
3. افتحي ملف [`config.js`](config.js) وضعي القيمتين:
   ```js
   window.TRACKER_CONFIG = {
     SUPABASE_URL: "https://xxxxxxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGciOi..."
   };
   ```
   > مفتاح `anon` مصمّم للنشر العلني — لا يمنح أي صلاحية خارج سياسات RLS المعرَّفة في `schema.sql`.

### ٥. انشري الموقع
**الأسهل — GitHub Pages:**
1. ادفعي التغييرات إلى الفرع `main`.
2. **Settings** → **Pages** → Source: **GitHub Actions**.
3. بعد دقيقة يصبح الرابط: `https://<اسم-حسابك>.github.io/vibe-coding/`

**بديل بلا أوامر:** اسحبي مجلد المشروع إلى [app.netlify.com/drop](https://app.netlify.com/drop) وستحصلين على رابط فوراً.

### ٦. وزّعي الرموز
1. افتحي الرابط → **المشرفة** → سجّلي الدخول.
2. تبويب **الإعدادات** → قسم **رموز دخول المجموعات**.
3. عدّلي أسماء المجموعات وأرسلي لكل مجموعة رمزها.

## حدود هذه الأداة — بصراحة

- **رمز المجموعة ليس كلمة مرور.** من يعرف رمز مجموعة أخرى يستطيع الكتابة باسمها. هذا مقبول لمتابعة صفّية ويمنع الخطأ لا العبث المتعمّد. سجل الخطوات يوثّق من كتب وماذا، فأي تلاعب مكشوف.
- **الدرجات وحدها محمية فعلياً** — خلف حساب المشرفة على مستوى قاعدة البيانات.
- إن أردتِ حماية أقوى للمجموعات: أنشئي حساباً لكل طالبة في Supabase Authentication واربطي العضوية بالحساب. يضاعف وقت الإعداد ولا يضيف للتقييم شيئاً.
- الطبقة المجانية في Supabase تكفي هذا الاستخدام بفارق كبير، لكنها **توقف المشروع بعد ٧ أيام بلا نشاط**. الاستخدام الأسبوعي يبقيه حياً.
